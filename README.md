# ひらがな えあわせ

小学1年生くらいを想定した、絵やことばに対応するひらがなを書き、書き順を練習するブラウザゲームの初回プロトタイプです。

## 現在できること

- 現代かな表の46文字を収録
- 濁音、半濁音、小さい `ゃゅょっ` も練習用データとして収録
- タブレットのタッチ操作とノートPCのマウス操作に対応
- iPadやスマホ幅では、絵と問題を上、書く場所を下に配置
- iPadやスマホ幅ではメニューを初期状態で閉じ、必要なときだけレベル選択を表示
- 書き順の画ごとに開始位置を表示
- KanjiVG由来の各画SVGパスを使って、画ごとに色分けしたお手本線を表示
- 画の開始位置、終点、長さ、向きを簡易判定
- 正解時に `○`、お手本に近い形で書けたときに `◎` を描くアニメーションで表示
- 正解表示を数秒見せてから自動で次の問題へ進行
- 完了した文字数をブラウザ内に保存
- 保存された完了記録をリセット
- 文字一覧は初期表示せず、必要なときだけ開閉
- レベル0からレベル6まで自由に切り替え
- 保護者・先生向けの `おとな` パネルから、画像付きの追加問題を登録・削除
- 追加した問題は `おとな` パネルの問題一覧から直接テスト
- 追加問題と画像をJSONファイルでエクスポート・インポート
- レベル0は、お手本線ありで `あ` から `ん` まで順番に練習
- レベル1は、絵と1文字穴うめを見て、ランダムな1文字を練習
- レベル2は、絵を見て2文字のことばを練習
- レベル3は、濁音・半濁音を入れたことばを練習
- レベル4は、小さい文字を入れたことばを練習
- レベル5は、3文字以上のことばを練習
- レベル6は、短い文の `？` に入る1文字のつなぎもじを練習。導入の `が` / `を` の後、`は` / `へ` / `を` へ進行
- レベル1からレベル6は、最初はヒントなし、3回以上間違えるとヒントを自動表示
- ランダム出題は未出題を優先し、一巡するまで同じ問題が出にくい
- 直近3問に出た問題はできるだけ避けて出題
- レベルごとの目標数に達したら、`れべるクリア！` を表示して次の有効なレベルへ進行
- `つぎへ` ボタンで正解後の待ち時間をスキップ
- 子ども向けの画面文言は、なるべくひらがなで表示
- 保護者・先生向けの `おとな` パネルで、つまずいた文字、回数、理由を確認
- 保護者・先生向けの `おとな` パネルで、絵、問題、こたえ、書く文字の一覧を確認
- 絵とこたえの一覧は、レベル、標準/追加、文字検索で絞り込み
- 複数文字の途中は短め、単語や文の最後は少し長めの待ち時間で自動進行
- 小さい `ゃゅょっ` は、左下寄り・右下寄りに小さく書く場合も判定しやすいように調整

## 開き方

`index.html` をブラウザで開くと動きます。外部サービスや追加パッケージは使っていません。

## 追加しやすい場所

基本のひらがな問題は `script.js` の `lessons` にまとめています。ひらがな、ことば、絵、画ごとのなぞり線を追加すると問題を増やせます。

レベル1の穴うめ問題は `fillLessons`、レベル2の2文字単語は `wordLessons`、レベル3以降は `dakutenLessons`、`smallKanaWordLessons`、`longWordLessons`、`sentenceLessons` にまとめています。`sentenceLessons` は、`とり？とぶ。` や `がっこう？いく。` のような文のつなぎもじ問題として使います。

`おとな` パネルから追加した問題は、問題データをブラウザ内の `localStorage`、画像を `IndexedDB` に保存します。同じ端末・同じブラウザでは残ります。別端末へ移す場合は、`追加問題を書き出し` でJSONファイルを保存し、移したい端末で `追加問題を読み込み` からそのJSONファイルを選びます。

濁音、半濁音、小さい文字は、基本文字のSVGパスをもとに `extraLessons` として生成しています。

## レベル構成

- レベル0: お手本線ありで、`あ` から `ん` まで順番に書く
- レベル1: 絵と1文字穴うめから、1文字を書く
- レベル2: 絵を見て、2文字のことばを書く
- レベル3: 濁音・半濁音を入れたことばを書く
- レベル4: 小さい文字を入れたことばを書く
- レベル5: 3文字以上のことばを書く
- レベル6: `とり？とぶ。`、`がっこう？いく。` のような短い文を見て、`？` に入る1文字を書く

## レベル目標

- レベル0: 46文字
- レベル1: 10問
- レベル2: 10問
- レベル3: 6問
- レベル4: 6問
- レベル5: 5問
- レベル6: 8問
