## KanjiVG

This project includes adapted stroke path data for hiragana characters from KanjiVG.

- Project: KanjiVG
- Website: https://kanjivg.tagaini.net/

Adaptation in this project:

- Extracted stroke path `d` values for the 46 modern hiragana lessons from `あ` through `ん`
- Embedded them in `script.js` as lesson stroke data
- Added simplified start/end points for touch interaction checks
